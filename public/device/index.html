Session defaults

  • Default quality on Connect: 720p (change per device before Connect).
  • Session requests expire in ~2 minutes if not approved.
  • Pairing codes expire in 5 minutes and are single-use.
  • Optional TURN improves connectivity on hard NAT networks.

Help & Safety

Privacy rules for remote camera and microphone.

  • Camera/mic never start until you tap Approve on the phone.
  • A foreground notification stays visible while sharing.
  • Live video uses WebRTC — frames are not stored in Firestore.
  • Photos/recordings save on the phone only when you capture/record on purpose.
  • Revoke trusted browsers anytime to block reconnects.
  • If live video fails on some networks, configure TURN on the server.
