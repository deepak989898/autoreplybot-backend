Settings notes

  • Camera/mic never start until you tap Approve on the phone.
  • Live video uses WebRTC (STUN; optional TURN via server env). Frames are not stored in Firestore.
  • Photos/recordings are saved on the phone only when you explicitly capture/record.
  • Pairing codes are hashed server-side; clients cannot read pairingCodes.
  • Session requests expire in about 2 minutes if not approved.
  • Deploy TURN credentials with TURN_URL, TURN_USERNAME, TURN_CREDENTIAL for restrictive NAT.
