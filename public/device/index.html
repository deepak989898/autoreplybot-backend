Help

Quick tips for remote modules.

Need help from an administrator? Use the Help button (bottom-right) to chat — you can also send images and videos.

  1. Pair this browser once from the phone.
  2. Enable the module on the phone Permissions card / Trusted Browsers.
  3. Screen mirror and recording always show Android’s official capture prompt.
  4. Installed Apps never uninstalls or installs silently.
  5. Recent Apps needs Usage Access on the phone; history is grouped by day (tap to expand).
  6. App Control closes blocked apps via Accessibility; Camera Lock needs Device Admin on the phone.
